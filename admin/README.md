# Consultório da Marcela

A página `/admin/` abre o calendário e a lista de pacientes. A ficha tem resumo, informações, chat e histórico dos checks do dia. A secretária usa `/secretaria/` com a própria conta; só a Marcela vê os logs. Dieta e anamnese ficam no WebDiet.

Consulte [o guia do consultório](CLINIC-WORKSPACE.md) para regras de acesso, registros e testes.
